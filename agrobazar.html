Agroobazar – Marketplace Seller Dashboard

Agroobazar is a marketplace platform designed to provide a seamless buying and selling experience. My role focused on designing the Seller Dashboard and creating the responsive mobile version of the platform from the existing desktop design.

The seller dashboard enables merchants to efficiently manage their business, including creating products, configuring shipping methods, processing customer orders, tracking order statuses, and managing customer reviews through a centralized interface.

01 — DESKTOP FIRST, THEN DOWN

Every screen designed twice, in the same system.

The wide view sets the hierarchy. The narrow view keeps it, reordering rather than removing.

A seller dashboard that opens on today's work

DESKTOP + MOBILE

Revenue and wallet balance first, then today's orders with a single ready-to-ship action, then active products with edit, discount and delete on each row. Mobile swaps the side navigation for a bottom bar.
