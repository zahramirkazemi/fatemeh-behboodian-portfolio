Taxi Shahr – Bilingual Ride-Hailing Application

Taxi Shahr is a ride-hailing platform designed to connect passengers and drivers through a seamless transportation experience. The project includes dedicated applications for both user and driver workflows.

My responsibility was designing the English (LTR) version of the application, ensuring a consistent user experience across all passenger and driver interfaces. This included adapting layouts for left-to-right reading, expanding the existing Design System with English-specific components, and creating interactive prototypes.

01 — PASSENGER APP

Booking a ride, tracked the whole way.

The passenger application allows users to book rides by selecting pickup and destination locations, track their driver in real time, manage payments, and review trip history.

22 CORE SCREENS, INCLUDING:
Authentication
Home
Map & Ride Request
Live Trip Tracking
Driver Profile
Trip Details & History
Wallet
Profile
Support
About Us
02 — DRIVER APP

The other side of the same trip

The driver application enables drivers to review ride requests, accept or reject trips, communicate with passengers, and manage ongoing activities.

18 CORE SCREENS, INCLUDING:
Ride Requests
Accept / Reject Flow
Trip History
Chat
Wallet
Ratings
Driver Profile
